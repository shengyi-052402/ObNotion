# 设计模式来源整理

## 摘要

这组来源对 23 种设计模式中的核心实用模式（工厂方法、策略模式、责任链模式）进行了细致拆解，并深入结合了真实项目中的“多登录方式重构”、“订单责任链处理”等实践，同时结合已有的 Spring 框架设计模式，系统归纳了设计原则与落地应用。

- [Spring 中的设计模式详解](Clippings/Spring 中的设计模式详解.md) - Spring 框架内部各种经典设计模式的应用实现。

## 关键信息

- **工厂方法模式**：解耦对象创建过程，分为简单工厂（非正式模式，违反开闭原则）、工厂方法（子类延迟实例化）、抽象工厂（多产品族/产品等级）。
- **策略模式**：封装可互换的算法逻辑。结合 **Spring 容器感知与 Map 存储**，设计“登录策略工厂（UserLoginFactory）”，完全消除 UserService 中繁琐的 if-else。
- **责任链模式**：将请求沿链条传递给合适处理器。在 Spring Web 开发中体现在 Filter 和 Interceptor 拦截机制。
- **Spring 内部设计模式**：单例（Singleton Bean）、代理（AOP 动态代理）、模板方法（JdbcTemplate）、观察者（ApplicationListener 监听机制）。
