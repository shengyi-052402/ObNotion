# 微服务来源整理

## 摘要

这组来源围绕 Spring Cloud 与 Spring Cloud Alibaba 五大核心组件，深入讨论了注册中心与发现、负载均衡策略、服务雪崩及降级熔断方案、链路追踪、限流算法、分布式事务以及接口幂等性设计，是全面掌握微服务分布式治理的关键资料。

## 来源文件

- [微服务面试题-参考回答](Clippings/微服务面试题-参考回答.md) - 微服务组件、高可用注册、熔断限流、分布式事务及幂等设计。

## 关键信息

- 注册中心对比：Nacos (支持AP/CP, 支持主动检测与服务变更推送) 与 Eureka (AP, 仅心跳检测)。
- 负载均衡：Ribbon 核心策略（轮询、随机、区域敏感等）及客户端自定义配置方式。
- 服务保护：Sentinel/Hystrix 熔断触发机制（10s 内失败率超 50% 等）与降级。
- 链路监控：SkyWalking 性能追踪与告警机制。
- 限流算法：漏桶算法（Nginx, 绝对平滑）与令牌桶算法（Gateway, 允许突发流量）。
- 分布式事务：Seata AT 模式双阶段提交及基于 undo-log 的回滚机制。
- 幂等性：下单业务采用 Token + Redis 的拦截与校验防重机制。
- 任务调度：XXL-Job 路由策略（轮询、故障转移、分片广播）及故障重试。
