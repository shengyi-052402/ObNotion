# 常见技术与系统场景来源整理

## 摘要

这组来源涵盖了系统开发中最普遍的通用技术落地场景（单点登录 SSO、RBAC 权限设计、数据加密安全性），以及系统上线后的运维、诊断与日志采集体系（ELK 集群容器化搭建、Linux 日志过滤实操、Arthas 线上诊断、性能压测指标）。

## 来源文件

- [常见技术场景](Clippings/常见技术场景.md) - 单点登录、数据安全、系统诊断、Linux日志命令及项目棘手问题排查。
- [ELK搭建](Clippings/ELK搭建.md) - Docker 容器化部署 Elasticsearch/Kibana/Logstash 及项目 Logback 日志采集实操。

## 关键信息

- **认证与鉴权**：SSO单点登录的核心（微服务 JWT 网关认证模式）；基于 RBAC 的 5 表/7 表经典权限模型流转（张三 -> 角色 -> 权限 -> 菜单）。
- **敏感数据安全**：对称加密（AES/DES, 速度快, 大文件, 手机号身份证等）与非对称加密（RSA/DSA, 安全性极高, 小文件/数字签名/接口鉴权）。
- **ELK 集群**：Docker 构建 `elk-net` 桥接网络；ES 单节点启动挂载、Kibana 汉化绑定；Logstash 通过 tcp-json_lines 收集并按日期切分 index。
- **系统诊断**：`tail -f`、`grep` 与 `sed` 范围搜索等 Linux 实战命令；Arthas 核心诊断能力；压测关注的 QPS、吞吐量、响应时间、I/O 等核心指标。
