# 消息中间件来源整理

## 摘要

这组来源全面覆盖了 RabbitMQ 和 Kafka 两个主流消息队列的核心技术与面试要点，重点剖析了如何保障消息不丢失、解决重复消费/幂等性问题、实现延迟队列与惰性队列、处理消息堆积以及两者的核心高可用/高性能架构设计。

## 来源文件

- [消息中间件面试题-参考回答](Clippings/消息中间件面试题-参考回答.md) - RabbitMQ 与 Kafka 的高可用、高性能与可靠传输。

## 关键信息

- **RabbitMQ 消息防丢**：生产者 Confirm、交换机/队列/消息持久化、消费者手动/自动 ACK 与异常重试投递。
- **RabbitMQ 延迟队列**：基于死信交换机（DLX）+ TTL 实现，或采用延迟队列插件。
- **RabbitMQ 堆积与高可用**：使用惰性队列（直接存盘）容纳百万堆积；集群高可用从镜像队列（主从异步）升级到仲裁队列（主从 Raft，强一致）。
- **Kafka 消息防丢**：生产者异步回调与重试；Broker 端 acks=all 强一致同步与多副本 ISR 列表；消费者手动提交 Offset。
- **Kafka 顺序消费**：利用同一 Partition 内部有序的特性，发送时指定相同 Partition 或利用相同业务 Key 计算 Hash 分区。
- **Kafka 高可用与高性能**：零拷贝技术（Zero-Copy）、顺序读写、页缓存（Page Cache）、分批发送与消息压缩。
